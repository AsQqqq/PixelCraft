# ArtCraft brand files

The ArtCraft logo files (`artcraft-logo.svg`, `artcraft-logo-white.svg`, `artcraft-mark.svg`,
their PNGs and `LICENSE-brand.txt`) come from craftrules `assets/brand/` and are added by an
ArtCraft maintainer. They are trademarks under their own terms, not covered by this repository's
licence; see `LICENSE-brand.txt` once added.
